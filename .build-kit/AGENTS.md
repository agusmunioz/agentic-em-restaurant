# Build Kit — Accumulated Learnings

- Routes are auto-discovered by `server.ts` via a glob over `dist/src/slices/**/routes{,-*}.js` — never wire a route by hand anywhere else.
- Projections are NOT auto-discovered. A new `postgreSQLRawSQLProjection` must be imported into `src/common/loadPostgresEventstore.ts` and added to its `projections.inline([...])` array — this file is a documented slice-scope exception, safe to touch from a slice commit.
- Projection files each define their own local, disconnected `getKnexInstance()` (bare `knex({client:'pg'})`, used only to build SQL text via `.toQuery()` for `sql(...)` inside `evolve`). That is unrelated to `src/common/db.ts`'s `getKnexInstance()`, which is a real, connected instance — use that one for any executing query (GET routes, or a command handler that needs to read Postgres before deciding).
- `npm run run:checks` (`.build-kit/lib/check-commit-scope.cjs`) checks every uncommitted change by default, not just what you intend to commit. Stage only the target slice's files first, then run `node .build-kit/lib/check-commit-scope.cjs --staged` to get a true preview — otherwise unrelated pre-existing dirty files elsewhere in the working tree show up as false violations.
- If a command needs to locate its event stream by a field the stream isn't keyed on (e.g. a sibling slice already keyed its stream by some other field), don't invent a new request field to carry the missing key. Add a small, internal-only lookup projection scoped to the new slice's own folder (new table via a new `migrations/V{n}__*.sql`, new projection file, registered in `loadPostgresEventstore.ts`) and query it before loading the stream. Keeps the commit inside slice-scope and avoids touching another slice's already-committed files.
- This repo's git history has no merge commits — each slice is one commit on `feature/<slicename>`, fast-forwarded into `main`, then the feature branch is deleted.
- `.build-kit/.slices/**`, `progress.txt`, and this file are local-only bookkeeping for the Ralph loop — never staged into a slice commit (git history confirms none of the prior slice commits included them).
